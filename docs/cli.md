# CLI Reference

- `axiom init [name]` — initialize project
- `axiom inspect` — print effective config
- `axiom doctor` — diagnose setup
- `axiom config validate [--strict]` — validate config
- `axiom validate [--strict]` — alias
- `axiom compile [--target <t>] [--all]` — generate agent outputs
- `axiom verify` — report declared verification requirements
- `axiom agent detect|configure <t>|sync`
- `axiom skill list|validate <path>`
- `axiom preset list|activate <name>`
- `axiom profile list`
- `axiom workflow list|validate`
