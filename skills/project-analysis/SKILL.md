# Project Analysis

## Steps
1. Detect language/framework via manifests (package.json, etc.).
2. Map directory structure and entry points.
3. Identify existing patterns, conventions, test setup.
4. Note build/test/lint commands.
5. Summarize architecture and constraints.

## Output
- Stack summary
- Key directories
- Commands (dev/build/test/lint)
- Conventions observed
- Risks/gaps
